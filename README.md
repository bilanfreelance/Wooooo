# Wooooo — concept site

Concept website for a fictional branding & motion agency. **Not a real agency** — clients and cases are invented.

Single-page scroll story: a UFO flies in and its beam reveals the content.

- GSAP 3.12.5 + ScrollTrigger, Lenis 1.1.13 (CDN)
- Syne + Familjen Grotesk (Google Fonts)
- WebP images with mobile variants, MP4 + WebM video

Static site — open `index.html` or serve via GitHub Pages (branch `main`, root).

Design & development: [Valentyn Bilan](https://bilandesign.site)
